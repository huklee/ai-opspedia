Airflow 스케줄러 재시작 체크리스트

문서 ID SOP-DP-002 · 담당 데이터 플랫폼 · 스케줄러 재시작 뒤 catchup 으로 시간 단위 DAG 가 중복 실행되는 것을 막기 위한 절차.

재시작 전

  1. 시간 단위 DAG(candidate_gen_hourly) 의 max_active_runs 가 1 인지 확인
  2. 진행 중 태스크 확인: airflow tasks list-running

재시작 후

  • 중복 dag_run 확인 — 같은 hr 파티션이 두 번 쓰이면 랭킹 배치 OOM 대응 런북 참고
  • reco.candidates 파티션 행 수 확인
airflow dags list-runs -d candidate_gen_hourly --state running
