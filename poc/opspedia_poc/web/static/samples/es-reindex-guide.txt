상품 인덱스 리인덱스 절차 (텍스트 메모)

문서 ID: RB-SRCH-003
담당: 검색 인프라팀
최종 검토: 2026-09-20

1. 언제 하나
- products 매핑에 새 필드를 추가하거나 타입을 바꿀 때
- product_index_build 가 실패해서 수동으로 다시 만들어야 할 때

2. 사전 확인
- search.products 원천 적재가 끝났는지 확인
- 클러스터 health 가 green 인지 확인

3. 실행
    POST _reindex
    {"source": {"index": "products_v41"}, "dest": {"index": "products_v43"}}
$ curl -s localhost:9200/_cat/indices/products_v*?v

4. 검증
- 새 인덱스 문서 수가 기존 대비 ±5% 이내
- 전환은 상품 인덱스 alias 전환 · 롤백 런북을 따름
